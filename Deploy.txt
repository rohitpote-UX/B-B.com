1. EXECUTIVE OVERVIEW & CORE MISSION
--------------------------------------------------------------------------------
Brand Battle is a production-grade, enterprise-scale AI Product Intelligence and 
Comparison Platform. In traditional e-commerce (Amazon, Google Shopping, 
Flipkart), search rankings and recommendations are heavily polluted by sponsored 
ads, high-margin seller biases, affiliate commission priorities, and deceptive 
discounting schemes.

Brand Battle solves this fundamental market failure through a STRICT TRUST-FIRST 
PHILOSOPHY:
- Objective Data Dominance: Product matching, Knowledge Graph scoring, price 
  history evaluation, and AI recommendation engines run 100% independently of 
  commercial monetization.
- Monetization Isolation: Affiliate links and marketplace offer links are attached 
  ONLY after recommendation and comparison processing is completely finalized.
- Transparent Consumer Guidance: Provides 5-Year Total Cost of Ownership (TCO), 
  fake discount detection, 5-system consensus meters, and editorial clarity.

5. COMPONENT ANALYSIS: STRENGTHS & WEAKNESSES
--------------------------------------------------------------------------------
[1] PRODUCT KNOWLEDGE GRAPH (PKG)
- Strengths: Normalized entity representations, multi-attribute graph nodes, 
  resilient against marketplace naming noise.
- Weaknesses: High RAM usage when scaling to tens of millions of products.
- Mitigation: Implemented Redis caching and DB indexing on canonical slugs.

[2] HYBRID AI MATCHING ENGINE
- Strengths: High precision product matching across disparate retailers.
- Weaknesses: Complex text matching can slow down ingestion pipelines.
- Mitigation: Asynchronous background worker execution via FastAPI tasks.

[3] AI DECISION WORKSPACE
- Strengths: Unmatched consumer decision clarity with 20 behavioral UX features.
- Weaknesses: Requires rich spec coverage; sparse data reduces confidence score.
- Mitigation: Data completeness meters alert users to missing spec fields.

[4] SEO PUBLISHING PLATFORM
- Strengths: Automatic 100/100 SEO validation score, rich JSON-LD graph, ISR.
- Weaknesses: Massive sitemap generation requires chunking for large catalogs.
- Mitigation: Implemented Sitemap Index Record architecture.

[5] AFFILIATE COMMERCE PLATFORM
- Strengths: Sub-millisecond link generation (0.13ms), pluggable network adapters, 
  strict separation from recommendations.
- Weaknesses: External provider API outages can interrupt commission tracking.
- Mitigation: Fallback Engine instantly redirects users to direct retailer URLs.


6. DEPLOYMENT & OPERATION GUIDE
--------------------------------------------------------------------------------
PREREQUISITES:
- Python 3.12+ / Python 3.14
- Node.js 18+ / Node.js 20+
- Redis Server (Optional, fallback to in-memory)

LOCAL BACKEND SETUP:
1. Navigate to backend directory:
   cd backend
2. Install Python dependencies:
   pip install -r requirements.txt
3. Run backend automated verification test suites:
   py test_recommendations.py
   py test_price_intelligence.py
   py test_comparison_workspace.py
   py test_seo_platform.py
   py test_affiliate_platform.py
4. Start FastAPI server:
   py -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

LOCAL FRONTEND SETUP:
1. Navigate to Next.js frontend directory:
   cd frontend-next
2. Install npm dependencies:
   npm install
3. Execute production build test:
   npm run build
4. Start production Next.js server:
   npm run start -- -p 3000

ENVIRONMENT CONFIGURATION (.env.production):
- NEXT_PUBLIC_API_URL=https://api.brandbattle.com
- DATABASE_URL=postgresql://user:password@localhost:5432/brandbattle
- REDIS_URL=redis://localhost:6379/0
- AMAZON_AFFILIATE_TAG=brandbattle-21
- FLIPKART_AFFILIATE_TAG=brandbattle
- IMPACT_SUBID=bb_campaign
