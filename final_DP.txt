3. RECOMMENDED PRODUCTION ENVIRONMENT SETUP & DEPLOYMENT STEPS
================================================================================

STEP 1: PREPARE PRODUCTION ENVIRONMENT VARIABLES
Create a `.env` file on your production server (or Vercel / Render / AWS):

--- Backend (.env) ---
ENV=production
DEBUG=False
SECRET_KEY=generate_a_secure_random_64_char_secret_key_here
POSTGRES_USER=brandbattle
POSTGRES_PASSWORD=your_production_db_password
POSTGRES_DB=brandbattle_db
POSTGRES_HOST=your-postgres-db-host.com
POSTGRES_PORT=5432
REDIS_URL=redis://your-redis-host:6379/0
CORS_ORIGINS=https://b-b.com,https://www.b-b.com

--- Frontend (.env.production) ---
NEXT_PUBLIC_APP_URL=https://b-b.com
NEXT_PUBLIC_API_URL=https://api.b-b.com

STEP 2: DEPLOY BACKEND (FastAPI + Celery + Redis + PostgreSQL)
1. Run database initialization & soft migrations:
   python -c "from database import init_db; init_db()"
2. Start Uvicorn / Gunicorn production server:
   gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
3. Start Celery Worker for asynchronous price verification background tasks:
   celery -A tasks.celery_app worker --loglevel=info -c 4
4. Start Celery Beat Scheduler for TTL price refresh jobs:
   celery -A tasks.celery_app beat --loglevel=info

STEP 3: DEPLOY FRONTEND (Next.js)
1. Install dependencies and build production bundle:
   cd frontend-next
   npm install
   npm run build
2. Start Next.js production server (or deploy to Vercel/Cloudflare/AWS):
   npm run start
